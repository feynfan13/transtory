# CRH Transit Database

## Train type
### Coding system
The coding system is consisted of 4 numbers catenated by dash.
* The first number if for top-level series.
    - 1: CRH series
	- 2: CRH380 series
	- 3: CR400 series
	- 4: CR300 series
	- 5: CR200J series

* CR200J numbering system:
    - CR200Jx-A: 5-1-x-y
	- CR200Jx-B: 5-2-x-y
	- CR200JS-G: 5-3-0-0
	- CR200Jx-C: 5-4-x-y
